# Описание базы данных Rental Manager

В проекте используется PostgreSQL. Взаимодействие серверной части
с базой данных осуществляется с помощью Prisma ORM.

## Основные сущности

- Пользователи — учётные записи пользователей системы.
- Объекты недвижимости — информация об объектах, сдаваемых в аренду.
- Арендаторы — информация об арендаторах.
- Договоры — сведения о договорах аренды.
- Платежи — информация о начислениях и оплатах.
- Заявки — обращения, связанные с обслуживанием недвижимости.
- Сообщения — сообщения пользователей системы.

## Схема базы данных

Структура моделей и связи между ними определяются в файле
`server/prisma/schema.prisma`.
